# 🍕 Pizza Sales Analysis | MySQL & Power BI

## Project Overview
This project analyzes pizza sales data using MySQL and Power BI to evaluate business performance, identify customer ordering patterns, and understand product preferences.

The objective is to convert raw sales data into meaningful business insights that can support better sales and inventory decisions.

## Tools & Technologies
- MySQL
- Microsoft Power BI
- SQL
- CSV Dataset

## Key Performance Indicators (KPIs)
- Total Revenue: 817.86K
- Total Pizzas Sold: 49,574
- Total Orders: 21,350
- Average Order Value: 38.31
- Average Pizzas Per Order: 2.32

## Analysis Performed
- Daily and monthly order trends
- Hourly order trends
- Sales contribution by pizza category
- Sales contribution by pizza size
- Top 5 pizzas by revenue, quantity, and orders
- Bottom 5 pizzas by revenue, quantity, and orders
- Overall sales performance analysis

## Key Business Insights

### Sales Trends
- Friday recorded the highest daily orders, at approximately 3.4K.
- Sunday recorded the lowest daily orders, at approximately 2.7K.
- January and July showed relatively higher monthly order volumes in the monthly trend.

### Category & Size Performance
- Classic Pizza was the highest-selling category, contributing approximately 26.91% of sales.
- Large pizzas contributed the highest share by size, at approximately 45.89%.

### Best-Selling Pizzas
- Highest revenue: The Thai Chicken Pizza (43,434).
- Highest quantity sold: The Classic Deluxe Pizza (2,453).
- Highest number of orders: The Classic Deluxe Pizza (2,329).

### Lowest-Performing Pizzas
- Lowest revenue: The Brie Carre Pizza (11,588).
- Lowest quantity sold: The Brie Carre Pizza (490).
- Lowest number of orders: The Brie Carre Pizza (480).

## Business Recommendations
- Plan promotional campaigns around Fridays to leverage higher order demand.
- Review the performance of low-selling pizzas such as Brie Carre Pizza.
- Maintain sufficient inventory for Classic Pizza and Large-size pizzas.
- Use product-level sales performance to improve menu and inventory planning.
